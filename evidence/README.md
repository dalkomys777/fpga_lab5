# LAB5 예비 검증 증빙

각 FPGA 회로의 `vscode/` 폴더에 자기검사 실행 로그와 VCD 파형을 저장한다. Vivado 캡처, 합성·구현·타이밍 보고서, 보드 사진·영상은 본 실험 뒤 추가한다.

`report_captures/`에는 사용자가 VS Code에서 직접 촬영해 예비보고서에 삽입한 코드, 테스트벤치, PASS 및 파형 원본을 저장한다.

`00_setup/`에는 본 실험 직전 체크리스트, 증거 파일 목록과 소스·펌웨어 해시를 저장한다. `00_stm32/task3`, `00_stm32/task4`에는 현장에서 촬영할 디버그 화면·영상과 측정값을 저장한다.

Vivado 결과를 나중에 저장할 때는 `.gitignore`의 `**/vivado/` 규칙을 피하기 위해 폴더명을 `vivado_results`로 사용한다.
